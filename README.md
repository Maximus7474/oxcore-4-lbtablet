# Ox core bridge for LB tablet

## How to use ?
<!-- You really asking ? Whilst using ox_core ? -->

1. Add the bridge:
   * Add the client files to the client frameworks folder, in a folder called ox
   * Add the server files to the server frameworks folder, in a folder called ox
2. Change the config:
   ```lua
   Config.Framework = "ox"
   ```
3. Enjoy
